# Данные и код

`data/seed.csv` построен из предоставленного пользователем train.csv соревнования
https://www.kaggle.com/competitions/teta-ml-1-2025/data : случайная выборка с seed=42,
по 3000 строк из января, февраля и марта 2020 года. Полный исходник не включён.
Метки target настоящие; будущие месяцы синтетически получают те же метки при сдвиге
времени. Это учебная имитация, а не реальные будущие данные.

`examples/transactions.csv` — пример из ДЗ 1, ранее взятый из репозитория
https://github.com/chega8/mts25_mlops_hw2_real_time_fraud_detection .

Модель здесь обучается самостоятельно, готовый бинарник друга не используется.
Препроцессинг app/features.py разработан для ДЗ 3: циклические часы/дни недели,
флаги ночи/выходного, log/sqrt суммы, модуль разности координат, евклидова
разность координат и три категории. Это иной контракт, чем препроцессинг ДЗ 1.

Семинарский репозиторий использован как описание архитектуры:
https://github.com/NikitaMalykhin/mlops_realtime_fraud_detector_airflow .
Функции DAG и препроцессинг из него не копировались. Общий Kafka transport
переиспользован из собственного hw1.
